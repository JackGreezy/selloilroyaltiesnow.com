# Sell Oil Royalties project rules

- This project is a faithful, multi-page relabel of `gomspace.com`. Preserve the donor DOM, full-bleed hero, border-grid navigation, oversized typography, three-panel feature cadence, alternating media bands, carousel behavior, deep-blue detail pages, native form geometry, and distinct home/about/contact/index/slug page families.
- Every homepage release must contain exactly one visible, nonempty, SEO-driven H1 naming oil royalties and Williston, North Dakota. The hero must always contain a mapped local image; a blank hero is a release-blocking defect.
- This is a business website, not a personal blog. Singular first-person voice (`I`, `me`, `my`, `mine`, `myself`) is forbidden in authored and rendered copy. Owner questions use direct second person.
- The writing belongs only to `selloilroyaltiesnow.com`. Its voice is a Bakken production notebook: statement first, term second, consequence third, decision last. It explains decline, netback, title, and timing without unexplained jargon. Never move this voice into a shared pack, reusable template, or another site.
- Use only the mapped local inventory in `images/` and its staged `public/ours/` copy. No donor photos, remote content images, placeholders, empty media frames, or unrelated stock.
- Do not render miniature decorative pictures anywhere. Footer media must be exactly zero: no `img`, `picture`, `svg`, `video`, `canvas`, `iframe`, or `source`.
- The street address may exist only in metadata and in the query of exactly one Google Maps embed on the contact page. It must never appear as visible text.
- Keep all seven taxonomies visible and internally linked from the homepage and footer while preserving the donor's varied editorial cadence. Do not flatten the homepage into repeated generic box cards.
- A release requires capture parity, normalization, structural verification, compliance scanning, donor-versus-built visual review, desktop and mobile interaction QA, clean nested-repository git proof, and live Vercel route and form checks.
